# La Pomme Immortelle — Partie 2/4 : prompts pour Grok Imagine

**Règle :** ENCHAÎNE = mêmes personnages qui continuent la conversation → image de départ = dernière image du clip précédent. COUPE = nouveau personnage, moment important ou nouvelle scène → image de référence indiquée.

**Comment faire :** Grok Imagine → Vidéo → ajoute l'image indiquée (I1 = Golda + Kiwo, I2 = Mamie Prune + Clémentine, I3 = Docteur Pastèque + Ananas Jo, I4 = Bananito ; les autres paires = images recadrées du même nom) → colle le prompt → **6 s**, **plus haute qualité** → télécharge en **MP4**.
